# 0003. Async Command Polling and `kubectl-ate` + mTLS Router Client

Stock `atenet-router` Envoy listeners enforce a short route timeout (15s–60s) once a Judge Actor is awake, whereas an Antigravity SDK codebase evaluation (`uv run python -m app.judge`) runs for 3–9 minutes before completing. Rather than patching `ate-system`'s Envoy ConfigMap or holding open a 10-minute idle HTTP stream, the Judge Actor exposes `POST /execute/start` and `GET /execute/status/{job_id}` alongside synchronous `POST /execute`, and the Judge Orchestrator polls job completion over short (<1s) HTTP requests through `atenet-router` using projected PodCertificate mTLS (`podidentity.podcert.ate.dev/identity` and `servicedns.podcert.ate.dev/identity`) while driving control-plane lifecycle (`create actor`, `create egress-policy`, `delete actor`) via the bundled `kubectl-ate` (`v1.0.0`) CLI.
