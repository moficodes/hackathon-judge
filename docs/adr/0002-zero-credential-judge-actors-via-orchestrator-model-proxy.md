# 0002. Zero-Credential Judge Actors via Orchestrator Model Proxy

Under `kubernetes-sigs/agent-sandbox`, sandbox pods required `networkPolicyManagement: Unmanaged` and direct network access to the GKE metadata server (`169.254.169.254`) so the in-sandbox Antigravity SDK runner could mint Workload Identity tokens for Gemini on the Gemini Enterprise Agent Platform—exposing that service account token to untrusted repository code under evaluation. On Agent Substrate `v1.0.0`, Judge Actors hold zero cloud credentials and have no metadata server or Kubernetes ServiceAccount access; instead, `app.judge` points its Antigravity `VertexEndpoint` at the Judge Orchestrator's internal Model Proxy (`http://agent.hackathon-judge.svc.cluster.local:8000/vertex-proxy`), which attaches the Judge Orchestrator's Workload Identity token on the wire while per-actor `EgressPolicy` restricts outbound Actor traffic to the Model Proxy and public code/package hosts.
